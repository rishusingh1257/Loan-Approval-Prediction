    How it works

    The flow follows the way this project is actually built.

    1. 1

      Enter the application

      Provide the eleven details the model was trained on.

    2. 2

      Send it to the API

      The page posts your values as JSON to the FastAPI service, which validates them.

    3. 3

      The model processes it

      The trained Scikit-learn pipeline turns the submitted features into a prediction.

    4. 4

      See the result

      The page shows the returned status and the model's approval probability.

    This project does not connect to banks, check credit bureaus, or make official lending decisions.

    Responsible AI and privacy

    This application demonstrates Machine Learning-based loan prediction. Its output is an estimate generated by the trained model and is not a guarantee of loan approval or a substitute for an authorized lender's assessment.

    The model has not been evaluated here for fairness, bias, or regulatory compliance, so no such claim is made. The page asks only for the fields the model requires and does not store applicant data in the browser.
